# Bỏ ảnh năm 1 → năm 4 vào đây

Tên file phải đúng:

- `year1.jpg` — Năm nhất
- `year2.jpg` — Năm hai
- `year3.jpg` — Năm ba
- `year4.jpg` — Năm tư

Định dạng `.jpg` hoặc `.jpeg` đều được (nếu dùng `.png` thì sửa lại `src` trong `index.html`).

Nếu chưa có ảnh, các ô ở Trang 2 sẽ hiện placeholder thay thế — không bị vỡ giao diện.
